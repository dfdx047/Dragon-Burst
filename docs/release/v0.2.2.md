## PT

Um só APK para os CPUs ARMv8.2 e para os ARMv8.0 mais antigos (Snapdragon 665 e afins).

Novidades
- O APK leva o jogo compilado duas vezes: para ARMv8.2 (Snapdragon 675/730/845 e mais novos, Unisoc T770, Dimensity), com os atómicos LSE em linha, e para ARMv8.0, para os CPUs sem LSE (Snapdragon 660/665, Exynos 9611 e outros só com Cortex-A73/A53). O app escolhe sozinho pelo CPU, ao importar ou ao atualizar. Nos aparelhos ARMv8.2 nada muda em desempenho; nos ARMv8.0, que até aqui fechavam ao abrir o jogo, agora ele arranca.

Problemas conhecidos
- Nos aparelhos ARMv8.0 o desempenho ainda não foi medido (testado no Xiaomi Mi A3, Snapdragon 665 / Adreno 610). São aparelhos abaixo do mínimo testado: comece pela predefinição Mínimo (480p).
- O APK fica maior (cerca de +40 MB): leva os dois conjuntos.

## EN

One APK for ARMv8.2 CPUs and for older ARMv8.0 ones (Snapdragon 665 and similar).

New
- The APK carries the game built twice: for ARMv8.2 (Snapdragon 675/730/845 and newer, Unisoc T770, Dimensity), with LSE atomics inline, and for ARMv8.0, for CPUs without LSE (Snapdragon 660/665, Exynos 9611 and others with only Cortex-A73/A53). The app picks one on its own from the CPU, when importing or updating. On ARMv8.2 devices performance does not change; on ARMv8.0 ones, where the game used to close at launch, it now starts.

Known issues
- Performance on ARMv8.0 devices is not measured yet (tested on the Xiaomi Mi A3, Snapdragon 665 / Adreno 610). These devices are below the tested minimum: start with the Minimum preset (480p).
- The APK is bigger (about +40 MB): it carries both sets.
